# Yggdrasill · 推进必签的判定（rituals/read-gate）
> **id** rituals/read-gate · **幕** all（任何推进动作前） · **触发** 执行 `requirement.dispatch` / `proposal.submit` / `gate.approve` / `coordinate.submit` 之前
> **读不到代价** hard-refusal（缺签 / 过期 / 跨幕 / 他人签署 → 门禁 fail-closed，主状态不动）
> **ver** c592c7

> **定位**：签名该消费什么（正文通读 vs 版本核对）、窗口规则、维度与拒台词归属的**可判定形式**。规则本体见 [../../wiki-governance.md](../../wiki-governance.md)「幕进必读与推进必签」；本文件只给执行侧判定，不改写规则。

## 1. 判定输入

三个事实：磁盘上的 `ver`（`scripts/docs-ver.sh` 的产物）、你上次**正文通读**的 `ver`、以及距上次通读的**派发距离**与是否发生**上下文丢失**（压缩 / 新会话 / 交接）。

| 情形 | 必做 | 合规的样子 |
| --- | --- | --- |
| 磁盘 `ver` ≠ 你上次读的 `ver` | **正文通读**，再签名 | 能说出这次改了什么 |
| `ver` 相同，距上次正文通读 ≤ `readGate.window`（缺省 80 次派发），无上下文丢失 | **版本核对**（确认磁盘 `ver` == 已签 `ver`）后签名 | 回执写 `was=<ver> now=<ver>`；这不是通读 |
| `ver` 相同，但超窗口，或上下文丢失 | **正文通读**，再签名 | 通读在本会话记录里 |

**版本核对永不延展窗口：只有正文通读会重置它。** `ver` 就是内容身份（固定头 token 抹成 `000000` 后取 `git hash-object` 前 6 位，共 6 位十六进制 = 24 位前缀，是变更探测器不是完整性证明），所以"文档可能已改"由版本核对覆盖；版本核对覆盖不了的是**你自己的记忆衰减**——那由窗口与上下文丢失触发测量。机制只检查 `ver` / 期次 / 窗口：签名声明"我签了"，永不声明"我读了"。

## 2. 签名

```text
<egg> open <run-root> --actor <who> --event config.set --payload '"read.<doc-id>=<ver>"'
```

`doc-id` = 该文件的固定头 `id`（如 `acts/coordinate`）；同一 `(动作, 文件)` 换人执行须由**执行此动作的人**重签。

## 3. 维度与拒台词

| 维度 | 触发 | 文案键 |
| --- | --- | --- |
| 覆盖 | 该幕必读文件没有本动作执行者的签名 | `read_gate_missing` |
| 新鲜 | 签的 `ver` ≠ 磁盘 `ver` | `read_gate_stale` |
| 遗忘 | 跨幕未重签，或超 `readGate.window` | `read_gate_forgotten` |
| 按人 | 签了但不是你签的 | `read_gate_other_actor` |

空签署人（旧存档）不参与「按人」维；人工菜单点击结构上无宿主章，降级为 any-signer 并在回执告明（否则 `guide` 模式会被锁死）。**amend 与两路打回推进 `rev` 时，签名在同一事务里被销光**，下一个推进动作报的是「覆盖」而不是「签名过期」——所以不存在"签名早于新 rev"这个可达状态。

## 4. 不可读即停

路径不存在、文件被移动、正文与索引矛盾——一律**停机报告**，不得据记忆推进；不得用前几行或一次 `grep` 命中冒充"读过了"。
